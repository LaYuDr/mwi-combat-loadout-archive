# 配装档案助手使用说明

版本：0.1.0　日期：2026-10-26

## 安装

1. 打开 Tampermonkey，选择“添加新脚本”。
2. 打开同目录 `mwi_combat_loadout_archive.user.js`，将全部内容复制到脚本编辑器，替换默认内容并保存。
3. 刷新模拟器网页。右下角出现“配装档案 · 数量”。

支持的网站：

- https://mwi-combatsi-mulator.pages.dev/
- https://azhu949.github.io/MWICombatSimulator/

本脚本只运行在这两个网站，不涉及强化助手，不匹配游戏域名。使用现代单人 JSON 不需要游戏端脚本。
需要从游戏一键导入时，请继续使用网站原有的“MWI Combat Simulator 主站一键导入”脚本。

## 保存配装

### 从游戏导入

1. 保持原一键导入脚本已启用，按它的正常流程导入当前角色或已缓存队友。
2. 网站确认成功后，本助手按角色归档到“最近导入”。导入失败、未收到回执或格式不支持，不会显示保存成功。
3. 打开“配装档案”，选择记录，输入名称并点击“另存为配装”。

每个角色的“最近导入”随成功导入更新；内容不变时不重复新增。命名配装是独立记录，后续导入不会覆盖。
队伍按每个成功导入的成员分别归档；失败成员不归档，不保存为一个团队整体快照。

### 保存网站手动调整后的方案

本助手归档的是导入载荷，不读取网站私有状态，所以不会自动采集网站内后续手动调整。

1. 在网站原生“导入/导出”中，为当前方案导出“现代单人”JSON 并下载。
2. 在本助手中点击“导入 JSON”，选择该文件。
3. 等待校验完成，核对份数，点击“添加档案”。

同样支持网站现代组队 JSON（拆分为单人命名档案）及本助手的 JSON 备份。
校验失败时不会部分导入；文件最大 20 MB、最多 500 套，单套原始载荷最大 2 MB。
重复导入相同名称和内容的命名配装会跳过，不覆盖现有记录。

## 载入配装

1. 打开模拟器主页，等待网站加载完成。
2. 从档案列表选择配装，选择目标“玩家 1～5”。
3. 点击“载入玩家 N”，等待出现“已载入玩家 N”。

载入只替换选中槽位的角色字段，不清空、切换或勾选其他玩家。网站可能重置该玩家已有的优化结果。
档案仍保留，载入不要求游戏页面在线，也不会再次生成一份自动档案。
网站有未保存的编辑或接口未就绪时，会显示失败信息；处理编辑或等待网站加载后重试。

## 数据范围

白名单保存角色名称/角色 ID、技能等级/经验、战斗装备及强化等级、战斗技能、食物饮品、触发条件、房间、成就和公会增益。
按源格式支持当前角色、可分享队友资料和网站现代单人数据。空槽、显式零和空触发器保留。

不保存账号对象、凭据、聊天、完整背包、物品 hash、市场全量估值、地图和时长、全局迷宫升级。
载入不切换地图/时长/全局迷宫设置。源数据缺少某些角色加成时，遵循网站已有导入规则，可能沿用目标槽位原值或回退默认值，详情会提示需核对的字段。
采集时间是本助手收到导入请求的时间，不代表队友资料在游戏内更新的时间。

原协议未提供可靠服务器标识，界面显示“服务器未提供”。最近导入用可见角色 ID 和名称区分。
若跨服务器存在完全相同 ID 和名称，无法可靠自动区分，请显式另存命名配装；不要把推测当作服务器身份。

物品详情以 HRID 展示。若页面已加载该物品图标，会复用其中可安全复制的图形；否则显示占位图标，不额外请求资源。

## 备份、删除与迁移

- “导出这一套”：导出当前档案。
- “备份全部”：导出所有未删除档案，不包含回收站。重要档案请定期备份到文件。
- “移入回收站”：可立即撤销，或在“回收站”筛选中恢复；本版不提供永久删除或清空。
- 跨镜像、浏览器或设备迁移：先导出，再在目标网站导入 JSON。

数据存放在当前网站的独立 IndexedDB，清除网站数据或更换浏览器会影响存档。
两个镜像的档案库互相独立，不是云同步。网站原生“保存/恢复玩家配置”不会管理本助手的档案。

正式运行时不发送网络请求；开发加载器会从本机 127.0.0.1:4178 读取运行时；载入操作会把所选配装交给当前模拟器网页处理。

## 更新与故障处理

手动替换同一脚本的代码后保存并刷新网站；数据库名和 schema 保持兼容时档案继续保留。
正式版具有自动更新元数据，Tampermonkey 是否自动安装取决于其设置；安装更新后刷新网页执行。开发版刷新时从本机重新构建，不替换原一键导入脚本。

- 看不到入口：检查脚本已启用、网址正确，刷新网页。
- 没有自动档案：应先安装本助手再重新进行一次主站导入；先前导入无法回溯获取。
- 数据格式不兼容：原生导入仍可继续，保留其 JSON 用于适配；勿清空档案库。
- 存储不可用或已满：检查浏览器网站存储权限/空间，先备份已有数据，再重试。
- 未收到载入回执：回到主页并处理未保存编辑；档案不会因此删除。

验证已覆盖合成数据和真实网站接口；用户个人 Tampermonkey 安装与真实游戏取数需要安装后实际核对。
