# 安装与活跃统计

沿用公会、邀请、强化和资产助手的公共统计客户端，接收地址为 `https://ukpyedhl.cn-hk1.rainapp.top`，本助手标识为 `mwi_loadout`。

- 正式安装包默认开启，保留已经保存的关闭选择。可在原生配装详情中的“统计”查看隐私说明和关闭统计。
- 只发送插件标识、版本、随机安装标识的 SHA-256 摘要；不发送账号、角色、配装、迷宫档案、游戏操作或 Cookie，不使用硬件指纹。安装数不等于物理设备数或人数。
- 按北京时间每日去重；服务不可用时沿用客户端的退避重试，不阻塞助手功能。
- 关闭后本地立即生效，并仅尝试一次不含安装标识的关闭事件；不重试该事件。网络服务可见来源 IP，历史及备份没有自动删除期限。
- 开发加载器、本地 runtime 和迷宫测试服／外部模拟器不计入正式统计。

## 服务恢复后的配置

服务端 `allowed_plugins` 需保留原有标识并加入 `mwi_loadout,mwi_labyrinth`，统计面板可分别显示为“配装助手”“迷宫助手”。不得借用其他助手的标识，否则数据会混入原有助手。

本次只接入客户端和生成本地安装包，未连接、测试或修改统计服务器；远端是否已加入白名单尚未确认。
