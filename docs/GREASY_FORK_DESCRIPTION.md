# MWI 战斗模拟器配装档案助手

在模拟器主页原有配置区下方嵌入完整“配装档案”管理区，随网页滚动。保存网页当前调好的单人或整队配置，以后点击导入即可交回网页恢复；无需下载后再上传。

## 保存当前配置

1. 安装后刷新 [模拟器](https://mwi-combatsi-mulator.pages.dev/)。也支持 [GitHub Pages 镜像](https://azhu949.github.io/MWICombatSimulator/)。
2. 在主页下方的“配装档案”选择单人或整队；保存单人时选择来源玩家。
3. 按需填写名称，点击“保存网页当前配置”。助手调用网页原生导出，完整保存原生 JSON，包括在网页上手动调整后的配置与模拟设置。

每次保存新建快照，不覆盖已有档案；同名同内容会跳过重复添加。本助手不再自动归档主站一键导入消息，保存当前配置也不需要另装游戏端导入脚本。

## 恢复与管理

- 单人档案：选择目标玩家，再点击“导入到网页”。按网页原生规则替换该玩家与包内模拟设置，保留其他玩家配装。
- 整队档案：点击“导入整队配置”，核对包内玩家和模拟设置的替换范围后，明确确认才执行；网页可能重置原有优化结果。
- 支持名称修改、搜索、分类、下载原生 JSON、备份全部和可恢复的回收站，没有永久删除。
- “导入档案文件”支持网页现代单人、整队 JSON 和本助手新旧备份；先完整校验，再由你确认添加。添加档案本身不修改网页配置，整队文件不会拆成单人。

旧版档案保留并兼容读取，但只包含当时保存的数据，不含之后在网页上的修改；缺失字段由网页现有导入规则处理，请恢复后核对。

## 自动更新

正式版已配置 GF 更新地址，由 Tampermonkey 按设备上的更新检查和自动安装设置更新；更新后刷新模拟器执行新版。开发加载器使用本机源码，独立于 GF 正式版，请只启用一种。

## 隐私、备份与异常

插件不读取 Vue 私有状态、不调用游戏接口、不新增网络接口或上传角色资料。导出与导入由网页原生功能处理，其资产分刷新等行为仍遵循网页自身逻辑。

档案位于当前网站独立 IndexedDB，不调用网站的原生存档保存/清空功能。两个镜像、不同浏览器或设备之间的数据独立，可通过 JSON 迁移。清除网站数据前请先“备份全部”；备份不含回收站档案。

网页拒绝导入或没有确认成功时，不会显示恢复成功。超时、手动打断或额外弹窗会停止后续步骤，并保留可下载的原有输入文本备份；网页异步操作可能仍在运行，请核对状态后再试，不要连续重复导入。

本助手只在上述模拟器网站运行，与强化助手独立；不替代游戏端取数工具，不执行游戏操作。网页控件变化后可能需要更新适配。
