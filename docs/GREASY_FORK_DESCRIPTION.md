# MWI 战斗模拟器配装档案助手

在模拟器右下角增加“配装档案”，把成功导入的角色配装留在当前浏览器，支持命名、搜索、载入指定玩家槽位、回收站和 JSON 备份。

## 使用方法

1. 安装本脚本后刷新 [模拟器](https://mwi-combatsi-mulator.pages.dev/)。也支持 [GitHub Pages 镜像](https://azhu949.github.io/MWICombatSimulator/)。
2. 自动采集须另行安装网站原有的 [主站一键导入脚本](https://greasyfork.org/zh-CN/scripts/568613)。请在安装本助手后重新导入，成功回执后才会归档。
3. 打开“配装档案”，选择记录并“另存为配装”。命名配装不会被后续导入覆盖。
4. 载入时选择玩家 1～5，仅替换该槽位角色数据。源格式缺失的加成须核对，网站可能沿用原值或默认值。

网站内手动修改后的方案，请先从网站导出现代单人 JSON，再通过本助手“导入 JSON”并确认“添加档案”。本助手不自动读取这些手动调整。

## 保存与备份

支持网站现代单人、现代组队 JSON 和本助手备份；组队按单人分别保存。导入先校验，重复文件去重，错误文件不会部分写入。

“移入回收站”可撤销、恢复；没有永久删除。重要档案请使用“备份全部”导出。备份不含回收站档案。

## 隐私与限制

正式版不发送网络请求，不上传角色数据，不访问游戏账号或凭据。通过网站公开导入协议工作，载入会把所选配装交给当前模拟器。

档案位于当前网站独立 IndexedDB，不修改网站原生存档。两个镜像、不同浏览器/设备的数据独立，可通过 JSON 迁移；清除网站数据可能丢失档案。

不保存聊天、账号对象、完整背包或市场数据。未提供可靠服务器身份的载荷无法区分跨服同 ID 同名称，请另存命名配装。物品可能以 HRID 或占位图展示。网站接口变化可能需要更新适配。

本脚本与强化助手独立；不替代主站一键导入脚本，不执行游戏操作。
