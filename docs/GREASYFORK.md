# 配装助手

总览并编辑原生配装，保存不同场景的子方案，按高亮提示手动切换；记住生活与战斗项目的配装选择，让日常配置更省心。

适用于银河奶牛国际服和国服的游戏网页。安装后刷新游戏，打开「配装」即可使用。

## 配装总览

把各套配装按游戏顺序平铺展示，随页面宽度自动调整列数。装备、生活工具、技能、食物、饮料和触发条件集中查看，直接点击原生槽位即可更换或清空配置。

卡片中显示装备需求等级、指定强化等级、技能等级和持有数量，也可直接调整「默认」「缺失不提醒」「最高强化」。点击「详情」管理子方案；需要拖动排序时，切回「原生列表」。

## 场景子方案与切换指引

同一套原生配装下，可以保存单人、组队、迷宫等多个子方案，支持战斗、各项生活技能及「所有技能」配装。

- 保存装备和生活工具、强化模式、技能顺序、食物与饮料，以及完整触发条件。
- 选择子方案后，高亮有差异的槽位，显示目标配置；展开「差异」可查看「当前 → 目标」清单并定位。
- 打开原生选择列表时，用蓝色描边标出目标装备、技能或消耗品；指定强化等级时会一起核对。
- 手动修改后，差异随之更新，一致的项目会取消高亮。最高强化模式下，同一装备的不同强化等级不算差异。
- 支持更新、改名和移除子方案；移除后可在当前页面撤销。

保存的是当前打开的原生配装。点击子方案会开始对比，实际修改与装备仍由你手动完成。

## 行动配装记忆

在生活项目或战斗地点的行动详情中选过配装后，下次打开同一项目会自动恢复，刷新页面后也有效。「无配装」同样可以记住，未设置过的项目沿用游戏默认值。

不同角色、站点和项目分别记忆；同一战斗地点的不同难度共用记录。配装改名不影响记忆，已删除或不适用的配装会提示重新选择。助手只恢复配装选项，开始行动、加入队列和实际装备仍由你操作。

## 子方案怎么用

1. 打开「配装」，点击一套配装的「详情」，用原生控件调好配置。
2. 在「子方案」点击「＋」，输入名称并保存。
3. 选择一个子方案，按槽位高亮和差异清单手动调整。
4. 需要修改已保存内容时，点击「更新」，再点「更新方案」。

右键或长按方案标签可打开菜单，进行改名、移除、结束对比、导出和导入；键盘也可使用 Shift+F10。没有方案时，可右键或长按「＋」导入备份。

## 保存与备份

子方案和行动记忆保存在当前浏览器，按站点和角色分开；子方案还与所属原生配装关联，父配装改名不会丢失关联。

「导出全部」导出当前这套原生配装下的有效子方案，不包含已移除的方案或行动配装记忆。导入时须属于同一站点、角色和父配装；同名同内容会跳过，同名不同内容会提示，不覆盖已有方案。清理浏览器网站数据前，请先导出需要保留的子方案。

## 安装、更新与隐私

使用 Tampermonkey 等用户脚本管理器安装，更新后刷新游戏。正式版和开发加载器只启用一种。当前版本用于游戏网页，旧模拟器存档不会被读取或清理。

正式版默认开启安装与活跃统计，可在原生配装详情的「统计」中查看说明并关闭。仅发送插件标识、版本及随机安装标识的 SHA-256 摘要，不上传账号、角色、配装或游戏操作数据；统计服务仍可见来源 IP。开发加载器不参与统计。
